# vaibhavsiingh.github.io

My portfolio. Vite + React + three.js (react-three-fiber), GSAP + Lenis for scroll, matter-js for the skills playground.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

All copy lives in `src/content.ts`. Pushing to `main` builds and publishes to the `gh-pages` branch via GitHub Actions.

Easter eggs: press `~` for a terminal, or try the Konami code.
